Narration IR

Each animation starts from a written plan: what each spoken sentence means, and which spoken word each change in the picture is timed to. A program confirms that each quote in a plan is in its source file.

Limits: The program does not check whether a meaning is right, so I read each plan myself. Whether plans like this help a viewer understand has not been tested.
