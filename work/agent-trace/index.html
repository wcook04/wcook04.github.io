Agent Trace

Claude Code and Codex save every conversation as a file. Agent Trace lists those conversations as they run, shows each command beside what it returned, and copies the part you choose into another chat.

Limits: It shows only what the files recorded. Large outputs can be shortened, and it does not remove passwords from what it copies.
