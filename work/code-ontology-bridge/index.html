Code Ontology Bridge

A program that reads a Python project and writes a database of every function and which function calls which. Given that database of its own code, NVIDIA’s Auto Ontology, running a DeepSeek model, answered 10.3 of 12 questions correctly on average. The same model asked directly answered 3.2.

Limits: Twelve questions, written by AI models. The answer keys were corrected after the runs, which moved results in both directions.

Auto Ontology is NVIDIA’s open-source project. This study is independent of NVIDIA.
